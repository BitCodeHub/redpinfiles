The Red Pin Files Publisher ("the app") is an internal tool used only by the owner of the YouTube channel The Red Pin Files to upload that channel's own videos. This policy explains what data the app uses.

YouTube API Services

The app uses YouTube API Services. By using the app you agree to be bound by the YouTube Terms of Service. Information handled through YouTube API Services is also covered by the Google Privacy Policy.

What data the app accesses

  • An OAuth access token, granted by the channel owner, with permission to upload videos (youtube.upload) and to read the channel's basic details (youtube.readonly).
  • The channel's ID and title, to confirm uploads go to the right channel.
  • The IDs and status of the videos the app itself uploads.

The app does not access other users' accounts, comments, subscribers, analytics or any personal data of viewers.

How the data is used and stored

  • The token and the IDs above are used only to upload the owner's videos and confirm their status.
  • The token is stored only on the owner's own computer, in a file readable only by the owner's user account. Nothing is stored on third-party servers.
  • Upload records (video ID, title, date) are kept in the owner's own logs for as long as the video stays on the channel.

Sharing

The app does not sell, share, rent or disclose any data to anyone. It uses no cookies, tracking or advertising, and it has no other users.

Revoking access and deleting data

Access can be revoked at any time from the Google security settings page at https://myaccount.google.com/permissions (also reachable at https://security.google.com/settings/security/permissions). When access is revoked, the stored token stops working and is deleted from the owner's computer within 7 days. To ask for any other deletion, contact the address below.
